# Diagramas UML — SADUCI

Este directorio contiene los diagramas en formato Mermaid para el Capítulo 2.

## Estructura

```
diagramas/
├── uml/              # Diagramas UML (componentes, secuencia, clases)
├── flujo/            # Diagramas de flujo de procesos
└── secuencia/        # Diagramas de secuencia de llamadas
```

## Diagramas Disponibles

### Arquitectura
- `arquitectura-alto-nivel.mmd` — Componentes de alto nivel
- `despliegue.mmd` — Modelo de despliegue Docker
- `red.mmd` — Red de microservices

### Flujo de Datos
- `flujo-prediccion.mmd` — Proceso de predicción clínica
- `flujo-simulacion.mmd` — Proceso de simulación
- `flujo-autenticacion.mmd` — Flujo de login y JWT

### Secuencia
- `secuencia-prediccion.mmd` — Secuencia de llamada a predicción
- `secuencia-simulacion.mmd` — Secuencia de simulación
- `secuencia-autenticacion.mmd` — Secuencia de autenticación

### Clases
- `clases-prediccion.mmd` — Esquemas de predicción
- `clases-simulacion.mmd` — Esquemas de simulación
- `clases-usuario.mmd` — Modelo de usuario

### Base de Datos
- `er-prediction.mmd` — Entidad-Relación de prediction-db
- `er-simulation.mmd` — Entidad-Relación de simulation-db
